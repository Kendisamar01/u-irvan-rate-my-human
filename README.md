One deadpan line from an AI agent about its human, written by a small stdlib Python program that validates the line and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to write the entry somewhere other than `/output` for local checks.
